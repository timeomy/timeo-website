Support

NFCScribe reads and writes NDEF NFC tags on iPhone. This page answers common questions. If yours isn't here, email support@timeo.my.

Quick start

  1. Read a tag — Open the Read tab, tap Scan tag, hold the top of your iPhone against an NFC tag.
  2. Write to a tag — Open the Write tab, choose Text or URL, type your message, tap Write to tag, present a writable NDEF tag.
  3. See past scans — Open the History tab.

Compatible iPhones

iPhone 7 or newer running iOS 17 or later. iPad is not supported (no NFC hardware). The simulator cannot perform NFC scans.

Compatible tags

Any NDEF-formatted tag, including:

  • NTAG213 / 215 / 216 (most common retail NFC stickers)
  • MIFARE Ultralight, Ultralight C, Ultralight EV1
  • Type 2, Type 4, Type 5 NDEF tags
  • ICODE SLI, Topaz 512

Tags that are not NDEF formatted (e.g. raw MIFARE Classic, transit cards, payment cards) cannot be read or written by NFCScribe. This is an iOS hardware/policy limitation, not specific to our app.

Why does writing fail?

Common reasons:

  • Tag is read-only — once a tag has been locked (its OTP / lock bytes set), it can never be written again. NFCScribe will tell you when this happens. Buy fresh, unlocked tags if you need to write.
  • Payload too large — NTAG213 holds about 137 bytes of NDEF, NTAG215 holds 480, NTAG216 holds 868. NFCScribe checks size before writing.
  • Tag moved away too quickly — hold the tag steady against the top of the iPhone for at least 1–2 seconds.
  • Multiple tags in field — move the others away.

Why doesn't NFC work on my iPhone?

  • Make sure NFC permission is granted: Settings → NFCScribe → NFC
  • Use the top edge of the iPhone, not the back center.
  • iPhone case may be too thick or contain metal — try without the case.
  • iPad has no NFC hardware.

Where is my history stored?

In the app's private Documents folder on your iPhone. It is not synced to iCloud, and it never leaves the device. To remove all history, tap the trash icon in the History tab and confirm "Clear all", or simply uninstall the app.

Privacy

See the Privacy Policy. Short version: NFCScribe makes zero network requests.
